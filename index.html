How do I run the bot?

To run your Discord bot, first make sure all you fully extracted the file into your environment. Then find the .env file with your and put in your bot token. If you're hosting it online, upload your bot files there, set the startup command to node index.js, and run npm install to install all required packages. Then, just click the start button to launch your bot. If you're running the bot on your own computer, open a terminal in the bot's folder, run npm install to install dependencies, and then start it with node index.js.
